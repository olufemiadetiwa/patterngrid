# Image manifest

Generated by `tools/build-hero-frames.js` (`npm run images`). Hero frames are cropped for their display ratio around the recorded focal point, then encoded to WebP at the best quality within the byte budget (desktop ≤ 230 KiB, 1200 px ≤ 120 KiB, phone ≤ 140 KiB; quality floor 60). Section photographs load from the Unsplash CDN with a responsive srcset.

All photographs are stock imagery used as illustrative context. None shows Pattern Grid staff, premises or client sites. The founder has no published portrait yet; the founder pages use a text-led layout by design.
